## [1.0.0] - 2026-08-11
### Adicionado
- Automação de login (4 cenários) com Page Object Model
- Automação de cadastro (4 cenários) com Page Object Model
- Comandos customizados (Building Blocks) para login e cadastro
- Relatório mochawesome com exportação em PDF via Puppeteer
- Pipeline de CI (lint + testes) via GitHub Actions
- Pipeline de CD simulando ambientes de staging e produção
- ESLint + Prettier configurados no backend
- Documentação técnica e apresentação executiva
